# Glitch Box

[Sada](../README.md) · [Feature explorer](features.md#glitch-box) · [Changelog](../CHANGELOG.md#150--neon-sign-and-glitch-box-development-build)

Glitch Box shows the current cover art or track title in a compact panel. Track changes and musical accents trigger brief shifts in horizontal slices and red and cyan color separation. It is included in the **1.5.3** release.

## Add Glitch Box to a scene

1. Open **Desktop widgets** and choose **Glitch Box**.
2. Enable **Show Glitch Box** and use the scene editor to move or resize it. Size, opacity, and placement use the standard widget controls. The **Square** size preset suits cover art.
3. Enable **Show Glitch Box in full screen** to use it as an overlay. Enter full screen and drag it to save a position independent of the desktop placement.

## Tune its appearance

| Setting | What it changes |
| --- | --- |
| **Shows** | Choose **Album cover** or **Song title**. Cover mode falls back to the title when artwork is unavailable. |
| **Distortion** | Choose **Subtle**, **Medium**, or **Heavy**. |
| **Accent colors** | Choose **Album cover**, **Match the visualizer**, or **Custom**. |
| **Scanlines** | Toggle a fine horizontal texture across the panel. |
| **Music response** | Adjust how strongly musical onsets drive brief bursts. |
| **After playback stops** | Choose **Keep visible**, **Dim**, or **Hide**. Dim and hide take effect after six seconds. |

Select **Reset Glitch Box look** to restore its default appearance and effects. Save the scene to keep the selected settings and placement together.

<details>
<summary>Can I reduce the motion?</summary>

Use a subtle intensity and a lower music response for a quieter effect. Turning off Windows animations also disables the animated glitches.

</details>
